# RFIC2024 官方演讲语料风格测量（87 deck / 2536 页全量）

- 语料: `RFIC2024/2024_07_02_RMo01A_1/`（RMo01A–RTu04C 共 19 个分会，87 份论文演讲 PDF）
- 方法: PyMuPDF 全量逐 span 扫描（`analyze_corpus.py`→`corpus_stats.json`/`corpus_report.txt`；
  `deep_measure.py`→`deep_stats.json`；版式分类→`layout_stats.json`）+ 50 页渲染目检
  （`renders_rmo01a/`，覆盖全部分会）。
- 本文取代"4 份小样本"时代以 Zou deck 为默认参照的结论。**新默认 = 语料多数派 = RFIC 官方模板**。

## 0. 一句话结论

RFIC 演讲的"官方模板"高度统一：白底 959×540pt，**48pt Calibri-Bold 青绿 #197084 居中标题**，
正文 Calibri 32/28/24 三级 + **青绿圆点 bullet**，页脚青绿渐变色带（IEEE/MTT-S/SSCS 白 logo +
页码 + 会话号），RFIC 竖标左上 + 会议徽标右上；图占内容页 ~87%，对比表是标准收尾，
公式一律 Cambria Math。作者差异集中在字体族（Calibri vs Franklin vs Arial）与标题颜色（青绿 vs 黑）。

## 1. 页面骨架

- 页面: 959×540pt(16:9) 83/87 deck；2 deck 960×540；2 deck A4 横置 841.9×595.3（自制模板，离群）
- 纯白背景；内容带 y≈95–495；正文左边距中位 73pt（p10=22，图纸主导页可到 8–15）
- 页脚色带 y≈502–540 全宽青绿渐变（顶部黄绿细条）: 左 IEEE+MTT-S(+SSCS) 白 logo，
  中页码（封面计 0，黑或白 20–22pt 两派），右会话号（格式 `RMo1A-1` / `<RMo4A><1>` / `RMo2C-324-PU256`）
- 每页左上 RFIC 竖式蓝 logo（82/87 deck ≥80% 页出现）；右上会议徽标（Washington DC 2024）
- 2 deck 离群：无 logo、页脚下移（y≈533）、CIDFont 内嵌字（RMo04B_1、RTu03C_2）——自制导出模板，**不作为法典依据**

## 2. 标题（内容页）

- **字号: 48pt 为主（1729 页/2299 内容页 = 75%），长题降档 44/40/42**；测得谱系 32(超长题)/35/38.5/40/42/44/46/48
- **字体: Calibri-Bold 为绝对主流（x2085 vs Arial-BoldMT x199 vs Franklin x16）**
- **颜色: #197084 青绿 x1821 (79%) vs #000000 黑 x603 (26%)**（#1A6377 深青少量）
- 对齐: **居中 94%**（y≈20–75，单行为主）；无下划线/横线/色条
- 主题词短语或短句；系列页编号 `(1)(2)(3)` 或 `<1/5>` 直接写进标题

  （40/36 为长题降档）→ 作者 **24–28pt 粗体带上标**（报告人可加下划线）→ 单位 **20pt 粗体多行**

## 4. 公式书写（3624 个数学 span 实测）

- **字体: Cambria Math 一统（含空格名变体），无例外**。斜体 Times 假公式全语料仅 4 处（弃用做法）
- **字号: 展示公式 24–32pt**（众数 24/28/32），行内/展开式 16–20pt，上下标 10–14pt
- **颜色: 83% 黑**；术语着色 #0070C0 蓝（223）、#FF0000 红=关键项（211）、#7030A0 紫、#00B050 绿
  ——同一推导内不同项用不同颜色，并与后文波形/框图颜色呼应
- 步骤编号: **①②③ 带圈数字**（45/49 处），18.5–24.5pt，黑/蓝/红，放在公式行首或关键项上方
- 术语标注: 公式下方**大括号（olive/黑）+ 粗体短标签**（"DC Term"/"2X Frequency Term"）
- 推导链用 `→`/`=` 串联；关键结果行整行红/加粗；公式与图混排时公式居中、图占主位
- 生成规则: OMML=Cambria Math（数学引擎管斜体），汉字注释须显式 `<a:ea>`（见 SKILL.md 安全管线 §8）

## 5. 表格绘制（122 个"This work"对比页实测 + 目检）

对比表近乎标配（120 页含 "This work"，多数 deck 收尾前 1–2 页），三种流派：

| 流派 | 表头 | 行带 | 线 | This Work 强调 | 字号 |
|---|---|---|---|---|---|
| A 学术三线表（RMo01A_2 等） | 白底黑粗体 | 无带 | 横线 0.5–1pt，表头上下 2–3pt，无竖线 | 列值全部 **#0070C0/#0000FF 蓝** | 18–22pt 居中 |
| B 黑头填色带（RMo01B_5 等） | **黑底白粗体** | 灰 #D9D9D9/#D3D3D3 交替 | 无网格线（纯填充） | 表头字 **金黄** | 18–22pt 左对齐 |
| C 蓝头带（Th01C，IMS） | #58AECA 黑字 | #D1E3EC/#EAF2F6 交替 | 白 1pt 分隔，表头下 3pt | 行 #B3A2C7 紫 | 18pt 居中 |

- 全语料表填充色 Top: #000000、#FFFFFF、#D0E6CF/#E9F3E9（绿系带）、#D3D3D3/#CACACA（灰带）、
  #DBE4F0/#DEEEF4（蓝灰带）、#FCEADA（米色带）
- 线宽实测: 横线 0.5–1pt 为主，表头下粗线 2–3pt；竖线少见（1pt）
- 首列=参数名（可左对齐），数据格居中；**本工作列/行必须视觉突出**（换色/换带/表头金字三选一）
- 表下脚注: 上标 a/b/c 标记 + 18–20pt 说明行（"Including pads…"）

## 6. 图线规格（矢量重页描边直方图 + 目检）

- **线宽谱系**: 主体 1–2.25pt（轮廓、曲线、箭头）；细节 0.5–0.75pt；CAD 导出细线 0.25pt（原件居多，
  生成 deck **下限 1pt**，投屏才可读）；分组框/强调框 2–3pt
- **颜色语义**（跨 deck 共识）:
  - 黑 #000000/#252525 = 主体电路/结构；灰 #BFC0BF/#7F807F/#595959 = **非激活/参考路径**（弱化不删除）
  - 红 #FF0000 = 关键结果/警示框；蓝 #1A6EDF/#0070C0/#0000FF = 高亮路径/改进项；橙 #DF6C0E/#EF8228 = 第二高亮
  - 绿 #37AC6B/#00B050 = 正向标注/✔；紫 #7030A0 = 条件/备选
- **虚线**: 分组框（红/深绿 dashed 圆角矩形）、域边界、预测/外推曲线；点线 = sim，实线 = meas
- MATLAB 曲线 6 色序 + 1.5pt（沿袭 Zou 结论，语料一致）；波形条带每条左侧粗体彩色信号名与原理图路径同色
- 标注框: 白底 + 蓝 2pt 直角框（优 点列表 + ☺）；红虚线框 = 芯片照区域放大 callout；尺寸标注黑双箭头 + μm 数字
- 优点/缺点列表行尾挂 ✔(绿)/❌(红)；分类上色块（红 IC/蓝 IC 圆角矩形 + 白色子模块）
- die photo 页: 左 setup 实拍 + 右 micrograph，白实线框标模块名 + 尺寸箭头，红虚线从照片引出放大区

## 7. 版式原型（目检 21 页 + 全语料分类：带图页 ~87%、纯文字 ~12%、表 3%）

| 代号 | 原型 | 占比/用途 | 结构要点 |
|---|---|---|---|
| A | 左文右图 | 最高频 | 左 1/3 bullets（32/28pt），右 2/3 主图；图与 bullet 一一对应 |
| B | 双图并排 2-up | ~70% 页含≥2 图 | 两图各带小标题/各自 bullet；公共顶边对齐，中缝 x≈490 |
| C | 满版原理图 | 2–3% | 图占 85–100%，标题压图上；旋转 90° 侧标签分组；分块米色/绿色底 |
| D | 大图 + 底部 takeaway | 常见 | 图占上部 70%，底部 1–2 条 "X → Y" 结论，Y 蓝/红粗体 |
| E | 图左 + 波形条带右 | 常见 | 右侧 3–4 条时间轴波形竖排，信号名颜色与左图路径同色 |
| F | 概念示意 hero | 稀疏页 | 中央三角/五边形 tradeoff 图，大胆留白，中心红字命题 |
| G | Outline 进度页 | 13% | 三派：未到项灰化 / 灰底条+当前蓝底条 / checkbox（当前黑粗+青勾） |
| H | 对比表页 | 3% | §5 三流派；标题常为 "Comparison"/"Performance Summary" |
| I | 照片页 | 1–2 页 | 测量 setup 照 + die micrograph 标注 |
| J | 公式推导页 | 常见 | §4 规格；公式为主角，圈号步骤，括线术语 |
| K | 纯文字页 | 12% | Conclusion 4 条左右 32pt bullets；Acknowledgments + 居中 "Thank you for your attention." |
| L | References 页 | 1 页 | 15–20pt，[n] 编号，IEEE 格式 |

- 对齐纪律: 图公共顶边对齐；bullet 左缘对齐；正文不顶到页脚带（内容底 p90=492 < 502 色带上沿）
- 密度: "一页一口令"——每页 1 条 takeaway（Lead-in 或底部 takeaway 条承担），bullet 只给支撑点
- 系列页: 同一主题拆多页时标题加 `(n)`/`<n/N>`，版式保持一致只换内容

## 8. 结构节奏（87 deck 归纳）

1 封面（会话号/全题/作者+上标/单位；页码从 0 计）
2 Outline（3–6 条，32pt）→ **章节中途可重复插进度版**（灰化/高亮当前节）
3–N 技术主体: Motivation → Prior Art → Theory/公式 → 电路实现(系列页) → 仿真 → 版图/照片 → 测量 setup → 分项测量 → **Performance Comparison（表）**
N+1 Conclusion（复述 3–4 条贡献）→ Acknowledgments（基金/人名 + Thank you）→ References
- 附录/Backup 页**存在**（RMo01A_1 末页 "Appendix"，96 页超长 deck 含大量备份）——正式讲 15–35 页 + 可选备份
- 无 disclosure 页；会话号出现 2–3 处（封面顶部 + 每页页脚右侧）
- 超长 deck 离群: RMo02C_5=96 页（含完整推导备份链）、RMo01A_4=49、RMo04B_1=43、RMo03B_3=43、RMo02C_1=43
