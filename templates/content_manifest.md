# 内容清单合同（内容官产出物模板）

> 流水线第 1 步（内容官扇出）的每份产出必须遵循本合同。缺字段的条目视为未完成，
> 不得进入 Gate A 大纲阶段。

## 清单格式

每行一个信息点：

```
ID | 类别 | 信息点(一句话) | 数值/公式(如有) | 出处(文件+页码/图号) | 拟用版式原型(A-L) | 置信度(高/低)
```

- 类别 ∈ {motivation, prior_art, theory, circuit, layout, measurement, comparison, other}
- 出处必须精确到 PDF 页码或图表编号；"来源不明"的条目单独归入"待人类补充"区
- 公式必须写清变量含义与单位（进入 OMML 片段前的依据）

## 技术数据来源表（与 data_provenance.md 联动）

所有将出现在 slide 上的数值（增益、NF、PAE、频率范围、工艺节点、die 尺寸……）
必须逐条登记进 `templates/data_provenance.md`。风格可以自动生成，**数据必须有出处**。

|---|---|---|---|
| 电路图/曲线/照片/表格截图 | 论文图 N / 用户提供 | 原样 / 重绘 / 待处理 | |
